# NASCARforCubeSats

Git Repo of Ian Faber's academic results for the NASCAR for CubeSats project.



Each folder in this repository is from a different class where I investigated the idea of CubeSat racing. CubeSat racing is the idea of CubeSats attempting to traverse a randomized race course in the smallest amount of time while also minimizing the distance to the center of each ring in that race course. I investigated this project over 2 semesters - the original project was proposed in ASEN 6020: Optimal Trajectories at CU Boulder, and the project was expanded upon in ASEN 6014: Spacecraft Formation Flying and ASEN 5254: Algorithmic Motion Planning.



Each folder contains a final report that discusses the results of each exploration. In ASEN 6020, the project was proposed and primer vector theory was applied as a way to solve the problem. In ASEN 6014, assumptions were relaxed on the race course dynamics and controllers to maintain the race course formation were developed. In ASEN 5254, kinodynamic SST was proposed as an alternative to primer vector theory. Enjoy, and contact ian.m.faber@gmail.com with any questions!
